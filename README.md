♟️ Chess Game

A Chess Game developed in Unity (C#), focused on programming logic, object-oriented programming principles, and game development fundamentals.

A classic chess experience in retro pixel art style, featuring a minimalist 2D board and nostalgic visuals. Challenge your strategic skills in a clean and straightforward environment inspired by traditional chess.

🔗 Play Online: https://insaniis.itch.io/chess

🕹️ How to Play Online (itch.io)

Access the link:
👉 https://insaniis.itch.io/xadrez

Click "Run Game" (if available in your browser).

Wait for the game to load.

Start playing ♟️

⚠️ Recommended to use an updated version of Google Chrome or Microsoft Edge.

💻 How to Download and Run in Unity
📦 Download the Project

Clone the repository:

git clone https://github.com/YOUR-USERNAME/REPOSITORY-NAME.git

Or download it as a .zip file and extract it.

Make sure you have Unity Hub installed.

Install the same Unity version used in the project (check ProjectSettings/ProjectVersion.txt).

▶️ Open and Run

Open Unity Hub.

Click "Open".

Select the project folder.

After loading, open the main scene located at:

Assets/Scenes/

Click the Play ▶️ button inside Unity.
